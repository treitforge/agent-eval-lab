# Scan Ledger instructions

This directory contains a small Python teaching project.

Write short and direct documentation. Use active voice and present tense. Use one term for each item. Do not use idioms or contractions.

Run the tests with this command:

```bash
python -m unittest discover -s tests -v
```

Keep identifier normalization in `normalize_scan_id`. Preserve the public API. Preserve first-seen order. Use only the Python standard library.
