# Interface guidance

This directory contains the visual guidance that the RepoScout project uses. The files are copied into this repository so local evaluation tools use one interface contract.

Use these rules for a trajectory report:

- Make the evidence table the main surface.
- Use a compact workbench with a docked detail inspector.
- Use semantic tokens from `tokens.css`.
- Use green only for restrained actions and factual status.
- Do not use gradients, glass effects, large shadows, KPI card rows, or decorative chart panels.
- Keep machine values in a monospace font and use tabular numerals.
- Do not add winner language, ratings, severity, or editorial conclusions to a factual dashboard.
