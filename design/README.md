# Interface guidance

This directory contains the interface rules for Agent Eval Lab. Use these rules for each trajectory report and comparison dashboard.

Use these rules for a trajectory report:

- Make the trial comparison table the main surface.
- Use a compact workbench with a docked detail inspector.
- Use semantic tokens from `tokens.css`.
- Use green only for a primary action or factual status.
- Do not use gradients, glass effects, large shadows, KPI card rows, or decorative chart panels.
- Use a monospace font for machine values. Use tabular numerals for numeric columns.
- Do not add ratings, severity, preference, winner language, or editorial conclusions.
